# Campus Events Guide

Assignment 1 — UI design. A five-page static Campus Events website built with
hand-written HTML and CSS only (no JavaScript, frameworks, libraries, or templates).

GitHub repository: https://github.com/ali-fath-elbab/UI-Assignment1

## Pages

- `index.html` — Home with featured events
- `events.html` — Event catalogue
- `event-details.html` — Featured event details, media, and review form
- `schedule.html` — Event timetable
- `registration.html` — Event registration form

## Structure

```
campus_events_yourname/
├── index.html
├── events.html
├── event-details.html
├── schedule.html
├── registration.html
├── style.css
└── assets/            # event poster images
```

## Notes

- All local links use relative paths.
- Colors are driven by CSS custom properties defined in `:root`; dark mode is
  toggled with a CSS-only checkbox control.
- Tested in Chrome/Edge at mobile (375px), tablet (768px), and desktop (1280px).
